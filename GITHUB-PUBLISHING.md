# GitHub publishing policy

- Publish this site from the public GitHub repository named `sorabe`.
- Use `https://sorabe.jp/` as the canonical public URL.
- Keep repository names and public slugs short and specific to the website.
- Do not include personal names, AI product names, or internal tooling names in public URLs.
- Use GitHub as the default source and publishing workflow for future website projects.

The GitHub Pages workflow publishes the contents of `public/` and serves
`public/sorabe.html` as the site root.
